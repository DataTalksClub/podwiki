PyTorch is the second deep learning framework of module 8: the course rebuilds the image-classification model with torch optimizers, datasets, and DataLoaders, making the training loop explicit where Keras hides it. Learners see that the concepts — tensors, autograd, batches — are identical across frameworks.

Module 9 then ships a PyTorch model to AWS Lambda as a container, since the framework's dependencies exceed Lambda's unpacked size limit. Choosing between PyTorch and TensorFlow in the course is largely about which serving path fits the project.
