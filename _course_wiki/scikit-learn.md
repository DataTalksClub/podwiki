scikit-learn is the workhorse library of Machine Learning Zoomcamp's classical modules. After the course implements linear and logistic regression by hand with NumPy, scikit-learn provides the production-grade versions — LinearRegression, LogisticRegression, Ridge — plus DictVectorizer for one-hot encoding and the metrics module for RMSE, accuracy, and F1.

The tree module uses it for DecisionTreeClassifier, RandomForestClassifier, and the validation machinery (train_test_split, cross-validation), before the course switches to XGBoost for gradient boosting. The library's fit/predict interface is the pattern every later tool reuses.
