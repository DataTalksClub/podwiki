# Module 7: End-to-End Project Example (Optional)

This module was recorded in 2024 and has not been updated since
then. It is optional, but still useful to give you an idea of what
you need to implement for a course project.

We walk through building a complete RAG project from scratch: a
fitness assistant with search, evaluation, an API, monitoring, and
Docker containerization.

The final project is at
[alexeygrigorev/fitness-assistant](https://github.com/alexeygrigorev/fitness-assistant).
