Data Engineering Zoomcamp introduces PostgreSQL in Docker in module 1: pgAdmin and the database run as containers, the SQL refresher runs against them, and ingested taxi data lands in Postgres tables before the course moves to BigQuery. The streaming workshop's PyFlink pipeline writes its real-time output into PostgreSQL as the sink.

AI Dev Tools Zoomcamp uses Postgres as the app database: the full-stack app starts on SQLite and graduates to Postgres via Docker Compose once integration tests and deployments need a real engine.
