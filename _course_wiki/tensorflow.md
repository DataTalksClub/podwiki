Machine Learning Zoomcamp teaches deep learning in both major frameworks, with TensorFlow and Keras as the first path: Keras's Sequential API builds the clothing-classification model layer by layer, and the same network is reimplemented in PyTorch to show what each framework abstracts.

TensorFlow also owns the serving side of the course: TensorFlow Serving is the model server deployed on Kubernetes in module 10, and the serverless module packages a TensorFlow model into an AWS Lambda container, including the size workarounds its dependencies force.
