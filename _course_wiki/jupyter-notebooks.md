Notebooks are the default classroom across the Zoomcamps: Machine Learning Zoomcamp's lessons are Jupyter notebooks, Stock Markets Analytics runs entirely in Colab, and Data Engineering's workshops mix notebooks with pipeline code. They let each lesson pair explanation with runnable cells.

The courses are also explicit about the notebook's limit: notebooks are for exploration, not production. MLOps Zoomcamp's orchestration module turns a training notebook into a Python script before wrapping it in an orchestrator, and Stock Markets Analytics dedicates a module to moving from notebooks to deployable files with scheduling.
