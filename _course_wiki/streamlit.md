Streamlit is the recommended interface layer for LLM Zoomcamp capstones: a Python script becomes a shareable chat or question-answering UI without frontend work, which lets learners spend their time on retrieval and evaluation rather than web development.

The course's guidance pairs it with the monitoring loop — a Streamlit app that collects thumbs-up/down feedback alongside answers feeds exactly the feedback data the monitoring module teaches to analyze.
