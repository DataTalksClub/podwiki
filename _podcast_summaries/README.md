# Podcast Summaries

Agent-friendly routing notes for DataTalks.Club podcast episodes.

These pages summarize source episodes from `../../datatalksclub.github.io/_podcast`
without copying full transcripts. They are intended to help future agents decide
whether a source episode is worth opening for a research, wiki, or article task.

Scope rules:

- Treat the source podcast markdown files as the source of truth.
- Keep summaries compact and chapter-oriented.
- Prefer stable concept names that can be reused for wiki links.
- Generated records use `summary_status: source-index`. If a human or later
  agent adds compact source-derived notes, keep them short and preserve the
  canonical `source_url`.
